# Tripster GitHub Pages Website

เว็บไซต์ตัวอย่างตามภาพอ้างอิง พร้อม Responsive รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

## อัปโหลดขึ้น GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลด `index.html`, `style.css`, `script.js`
3. เปิด **Settings > Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด **Save**

## เปลี่ยนรูปภาพ

ค้นหา URL ที่ขึ้นต้นด้วย `https://images.unsplash.com/` ใน `index.html` และ `style.css` แล้วแทนด้วย URL รูปของคุณ
